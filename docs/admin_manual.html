Module 2

Orders Management & Courier Dispatch (`/admin/orders`)

Manage order fulfillment from the moment a client clicks confirm to final doorstep delivery and COD collection.

📦 Order Status Lifecycle Pipeline

1. Pending (جديد) ➔ 2. Confirmed (مؤكد) ➔ 3. Processing (تجهيز) ➔ 4. Shipped (مع المندوب) ➔ 5. Delivered (تم الدفع)
Order Action Button Button Appearance Exact Function
[ Status Dropdown ] Select box: Pending, Confirmed, Shipped, etc. Updates order status in Firestore and updates the client's live tracking bar instantly.
[ 🖨️ Print Thermal Invoice ] Printer Icon Button Prints an isolated packing slip with barcode, client phone, address, and COD total.
[ 📲 WhatsApp Client ] Green WhatsApp Button Opens direct chat with client with pre-filled greeting and tracking ID.
[ 🔍 Review Instapay Receipt ] Thumbnail Preview Modal Displays transfer screenshot with buttons to [ Approve ] or [ Reject ].
[ 🔄 Approve Size Swap ] Purple Alert Badge Approves client size exchange request and marks order for courier swap dispatch.
Module 3

Product Catalog & Inventory Management (`/admin/products`)

Adding new Haute Couture designs, setting dual-language titles, assigning colors, and managing stock counts.

✨ Adding a New Product Checklist

1. Names: English Name & Arabic Name (e.g. Linen Set / طقم كتان فاخر).

2. Pricing: Regular Retail Price + Optional Discount Offer Price.

3. Images: Drag-and-drop up to 5 photos (Auto-compressed to WebP).

4. Color Palette: Color name + HEX color picker (e.g. #DCC9A6).

5. Sizes: Toggle XS, S, M, L, XL, XXL, Free Size.

6. Stock Counter: Set physical inventory count per item.

Product Field / Action What It Does
[ + Add New Product ] Opens full publication modal with instant preview.
Discount Price Field When set lower than Price, automatically flags item as an Active Offer.
Featured Toggle Places the garment directly onto the Homepage curated showcase carousel.
[ Edit / Delete ] Modify existing prices or soft-delete discontinued garments safely.
Module 4

Discounts, Shipping Zones & 1-Click WhatsApp Recovery

Promotional codes, Egyptian shipping rates, and reclaiming lost sales with zero message fees.

🎟️ Promo Codes & Discount Engine (`/admin/discounts`)

Create vouchers like ARMIA10 (10% Off) or SUMMER150 (EGP 150 Off). Set minimum spend, expiration dates, and usage limits.

🚚 Shipping Rates for 27 Governorates (`/admin/shipping`)

Configure custom shipping rates per governorate (Cairo EGP 100, Giza EGP 100, Alex EGP 120, Sahel EGP 140) and set the Free Shipping Threshold (e.g. Orders above EGP 2,000).
